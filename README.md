****ASPNET-DT24TTC5-PHANDUCTRONG-WEBTRASUA****
**Đồ án:** Xây dựng website bán trà sữa Thông tin sinh viên Họ và tên: Phan Đức Trọng MSSV: 170124491 Email: trongpd190894@tvu-onschool.edu.vn
Giới thiệu Dự án xây dựng website bán trà sữa trực tuyến nhằm hỗ trợ khách hàng đặt món nhanh chóng và giúp cửa hàng quản lý đơn hàng hiệu quả. Hệ thống hướng đến trải nghiệm thân thiện, dễ sử dụng và tối ưu cho cả người dùng lẫn quản trị viên.
**Mục tiêu**
Xây dựng hệ thống bán hàng online hoàn chỉnh
Áp dụng kiến thức về ASP.NET và cơ sở dữ liệu
Tối ưu quy trình đặt hàng và quản lý
**Công nghệ sử dụng**
Backend: ASP.NET MVC
Fronted: HTML, CSS, JavaScript, jQuery,
Database : SQL Server
Tool: Visual Studio, GitHub
**Chức năng hệ thống**
Khách hàng
Xem menu trà sữa
Tìm kiếm và lọc sản phẩm
Xem chi tiết sản phẩm
Thêm vào giỏ hàng
Đặt hàng và theo dõi đơn
**Quản trị viên**
Quản lý sản phẩm
Quản lý danh mục
Quản lý đơn hàng
Quản lý người dùng
**Hướng dẫn cài đặt và chạy chương trình**
Bước 1: Clone project git clone: https://github.com/trongpd190894/ASPNET-DT24TTC5-PhanDucTrong-WebTrasua.git

Bước 2: Mở bằng Visual Studio
Bước 3: Cấu hình database
Import file .sql trong thư mục database
Cập nhật connection string trong web.config (đổi tên theo server name để chạy thành công)
Bước 4: Chạy hệ thống
Nhấn Run (F5)
